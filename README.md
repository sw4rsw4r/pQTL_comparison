# Overview

This repository contains the scripts and summary results needed to reproduce the analyses in this study.

Data availability

Individual level genotype and phenotype data from the UK Biobank are not included. This research used the UK Biobank Resource under Application Number 98032. Approved researchers can apply for access at https://www.ukbiobank.ac.uk/.

Variant level association results generated in this study are in data/RData/CASE1. Summary tables for the case studies and the negative control simulations are in summary_results.

The haplotype reference file ref/chr10.hap.gz was provided by the authors of Wallace, C. PLoS Genet. 16, e1008720 (2020) and is not included.

Protein association results from UKB-PPP, INTERVAL, and FinnGen were taken from the studies cited in the paper and are not redistributed here.

[Click here](https://sw4rsw4r.github.io/pQTL_comparison/pQTL_comparison.html) for an overview.
